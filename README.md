# DevOps Labs

Small hands-on labs, grouped by technology. Larger projects live in their own repos.

| Lab | What it shows |
|---|---|
| docker/node-hello | Dockerfile from scratch, layer caching, non-root, hardened Compose, PID 1 signal handling |
| docker/nginx-bindmount | Bind mounts (read-only) vs COPY |
| docker/notes-postgres | Node API + Postgres, healthcheck, named volume, `.env` secrets |

Related repos: flask-redis-docker, aws-resource-tracker.
